    Arbre de Décision QA

    Ce guide vous indique la procédure exacte à suivre sur SFI et QA MANAGER selon que la qualification soit une "Initiale" ou une "Prorogation".

    Explications Détaillées

    Cas d'une qualification INITIALE
    • Si c'est un "AV avec BP50" : La compétence est à notre charge. L'opérateur passe en statut QARJ. Le QLS Expleo rachète alors l'OP sur le logiciel SFI. Enfin, c'est au QLS OS de faire la validation finale dans QA MANAGER.
    • Si c'est une "CERTIF" : Vous ne devez pas intervenir ("PAS TOUCHE"). La gestion de cette qualification est assurée uniquement par les QLS. Votre seule mission est de fournir / envoyer le QCM au compagnon pour qu'il le remplisse.
    Cas d'une PROROGATION
    • Si c'est un "AV avec BP50" : La compétence reste sous notre surveillance. L'opérateur doit racheter lui-même son OP sur SFI. Dès que c'est fait, le QLS OS effectue la validation sur QA MANAGER.
    • Si c'est une "CERTIF" : Nous gardons la main. L'opérateur rachète sur SFI. Attention, une action supplémentaire est obligatoire : le compagnon doit remplir le QCM. Une fois validé, le QLS OS finalise sur QA MANAGER et s'assure d'y intégrer le résultat.
